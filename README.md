## Featured Projects

### [PowerShell Detection and Investigation with Wazuh and Sysmon](https://github.com/S-preme/wazuh-sysmon-soc-lab)

Built a Windows SOC home lab with centralized Sysmon logging in Wazuh. Investigated PowerShell alerts using command lines, parent processes, and user context. Created a custom rule extending a built-in encoded PowerShell detection and validated it against harmless encoded and normal commands.

**Focus:** Alert triage · Sysmon · Wazuh rules · Detection validation · MITRE ATT&CK

### [Azure Cloud SOC Honeypot](https://github.com/S-preme/Soc-Azure-Honeypot)

Deployed an Azure VM honeypot, forwarded logs to Log Analytics, and integrated Microsoft Sentinel to investigate activity targeting the exposed system.

**Focus:** Microsoft Azure · Microsoft Sentinel · Log Analytics · Security monitoring

### [Active Directory Home SOC Lab](https://github.com/S-preme/Active-Directory-Home-SOC-Lab)

Built an Active Directory lab with domain setup, baseline Group Policy hardening, firewall configuration, and Windows event log analysis.

**Focus:** Active Directory · Group Policy · Windows security · Event investigation

### Tines and Elastic SIEM Lab

Configured Elastic SIEM for log ingestion and threat detection, and integrated an EDR agent to monitor virtual machine hosts.

**Focus:** Elastic Security · EDR · Log collection · Endpoint monitoring

### [VirtualBox Setup Tutorial — YouTube](https://www.youtube.com/watch?v=LRRctkSP334)

Created and published a beginner-friendly walkthrough demonstrating how to set up and configure a virtual machine using Oracle VirtualBox.

**Focus:** Virtualization · Technical communication · User guidance
